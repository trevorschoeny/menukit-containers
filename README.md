# MenuKit: Containers has moved

This repository is archived. MenuKit: Containers now lives with MenuKit in one repository:

**https://github.com/trevorschoeny/menukit** (`menukit-containers/` folder, shared `docs/`)

The last release from this repository was `2.0.0+26.2`. From `3.0.0+26.2` on, the artifact builds from the combined repository, and the Java package is `com.trevlar.menukit`.

Issues: https://github.com/trevorschoeny/menukit/issues
